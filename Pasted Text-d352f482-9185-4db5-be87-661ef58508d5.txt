JSON-veebitokenide (JWT-de) kohta
Rakendusena autentimiseks või installipääsuloa genereerimiseks peate genereerima JSON-veebitokeni (JWT). Kui REST API lõpp-punkt vajab JWT-d, näitab selle lõpp-punkti dokumentatsioon, et lõpp-punktile juurdepääsuks peate kasutama JWT-d.

Teie JWT peab olema algoritmi abil allkirjastatud RS256ja sisaldama järgmisi väiteid.

Nõue	Tähendus	Detailid
iat	Väljastatud	JWT loomise aeg. Kellaaja triivi vältimiseks soovitame teil selle määrata 60 sekundit minevikku ja veenduda, et teie serveri kuupäev ja kellaaeg on täpselt seatud (näiteks võrguaja protokolli abil).
exp	Aegub kell	JWT aegumiskuupäev, mille möödudes ei saa seda enam installitokeni taotlemiseks kasutada. See aeg ei tohi olla kaugemal kui 10 minutit tulevikus.
iss	Väljaandja	Teie GitHubi rakenduse kliendi ID või rakenduse ID. Seda väärtust kasutatakse JWT allkirja kontrollimiseks õige avaliku võtme leidmiseks. Rakenduse ID-d leiate oma GitHubi rakenduse seadete lehelt. Soovitatav on kasutada kliendi ID-d. Lisateavet GitHubi rakenduse seadete lehele navigeerimise kohta leiate jaotisest GitHubi rakenduse registreeringu muutmine .
alg	Sõnumi autentimiskoodi algoritm	See peaks nii olema RS256, kuna teie JWT tuleb RS256algoritmi abil allkirjastada.
JWT kasutamiseks edastage Authorizationsee API-päringu päises. Näiteks:

curl --request GET \
--url "https://api.github.com/app" \
--header "Accept: application/vnd.github+json" \
--header "Authorization: Bearer YOUR_JWT" \
--header "X-GitHub-Api-Version: 2026-03-10"
Enamasti saab tokeni edastamiseks kasutada Authorization: Bearervõi Authorization: token. JSON-veebitokeni (JWT) edastamisel tuleb aga kasutada Authorization: Bearer.

#!/usr/bin/env python3
import sys
import time

import jwt

# Get PEM file path
if len(sys.argv) > 1:
    pem = sys.argv[1]
else:
    pem = input("Enter path of private PEM file: ")

# Get the Client ID
if len(sys.argv) > 2:
    client_id = sys.argv[2]
else:
    client_id = input("Enter your Client ID: ")

# Open PEM
with open(pem, 'rb') as pem_file:
    signing_key = pem_file.read()

payload = {
    # Issued at time
    'iat': int(time.time()),
    # JWT expiration time (10 minutes maximum)
    'exp': int(time.time()) + 600,
    
    # GitHub App's client ID
    'iss': client_id

}

# Create JWT
encoded_jwt = jwt.encode(payload, signing_key, algorithm='RS256')

print(f"JWT: {encoded_jwt}")

Näide: JWT genereerimine Bashi abil
Märkus

Selle skripti käivitamisel peate argumentidena edastama oma kliendi ID ja faili tee, kuhu teie privaatvõti on salvestatud.

Bash
#!/usr/bin/env bash

client_id=$1 # Client ID as first argument

pem=$( cat $2 ) # file path of the private key as second argument

now=$(date +%s)
iat=$((${now} - 60)) # Issues 60 seconds in the past
exp=$((${now} + 600)) # Expires 10 minutes in the future

b64enc() { openssl base64 | tr -d '=' | tr '/+' '_-' | tr -d '\n'; }

header_json='{
    "typ":"JWT",
    "alg":"RS256"
}'
# Header encode
header=$( echo -n "${header_json}" | b64enc )

payload_json="{
    \"iat\":${iat},
    \"exp\":${exp},
    \"iss\":\"${client_id}\"
}"
# Payload encode
payload=$( echo -n "${payload_json}" | b64enc )

# Signature
header_payload="${header}"."${payload}"
signature=$(
    openssl dgst -sha256 -sign <(echo -n "${pem}") \
    <(echo -n "${header_payload}") | b64enc
)

# Create JWT
JWT="${header_payload}"."${signature}"
printf '%s\n' "JWT: $JWT"

Järgmises näites asendage YOUR_PATH_TO_PEMsee faili teega, kuhu teie privaatvõti on salvestatud. Asendage YOUR_CLIENT_IDsee oma rakenduse ID-ga. Lisage kindlasti väärtused YOUR_PATH_TO_PEMjutumärkidesse.

#!/usr/bin/env pwsh

$client_id = YOUR_CLIENT_ID

$private_key_path = "YOUR_PATH_TO_PEM"

$header = [Convert]::ToBase64String([System.Text.Encoding]::UTF8.GetBytes((ConvertTo-Json -InputObject @{
  alg = "RS256"
  typ = "JWT"
}))).TrimEnd('=').Replace('+', '-').Replace('/', '_');

$payload = [Convert]::ToBase64String([System.Text.Encoding]::UTF8.GetBytes((ConvertTo-Json -InputObject @{
  iat = [System.DateTimeOffset]::UtcNow.AddSeconds(-10).ToUnixTimeSeconds()
  exp = [System.DateTimeOffset]::UtcNow.AddMinutes(10).ToUnixTimeSeconds()
  iss = $client_id
}))).TrimEnd('=').Replace('+', '-').Replace('/', '_');

$rsa = [System.Security.Cryptography.RSA]::Create()
$rsa.ImportFromPem((Get-Content $private_key_path -Raw))

$signature = [Convert]::ToBase64String($rsa.SignData([System.Text.Encoding]::UTF8.GetBytes("$header.$payload"), [System.Security.Cryptography.HashAlgorithmName]::SHA256, [System.Security.Cryptography.RSASignaturePadding]::Pkcs1)).TrimEnd('=').Replace('+', '-').Replace('/', '_')
$jwt = "$header.$payload.$signature"
Write-Host $jwt
